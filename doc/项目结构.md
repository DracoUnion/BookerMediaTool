# BookerMediaTool 代码结构

BookerMediaTool 是一个基于 OpenAI 兼容 API 的命令行媒体内容生成工具集，源自 BookerGptTool 的媒体管线子命令，包含小红书信息图、文章配图、网页 PPT、小红书轮播图、即刻文案、播客、公众号出稿、人脸融合等功能。

命令行入口两个：`BookerMediaTool` 与 `media-tool`，均映射到 `BookerMediaTool.__main__:main`（pyproject.toml `[project.scripts]`）。`__main__.py` 构建顶层 `argparse` 解析器（通用 LLM 参数与 `--debug`），注册 12 个子命令（`article-img`/`article_img`、`ppt`、`jike-art`、`podcast`、`gzh-art`、`xhs-art`、`xhs-img`、`zhanshimian`、`bili-ai-proj`、`zhihu-radar`、`wx-summary`、`aidaily`），最后 `args.func(args)` 派发执行。

代码全部位于 `BookerMediaTool/` 包内，按职责分为七类模块：

## 1. 入口与包元信息

+ `__main__.py` — 唯一 CLI 入口。构建顶层 `argparse` 解析器（`-m/--model`、`-k/--key`、`-H/--host`、`-r/--retry` 等通用参数，以及 `--debug`），注册 12 个子命令模块的 `reg_subparser`，最后 `args.func(args)` 派发。
+ `__init__.py` — 包元信息（`__version__` = 2026.10.29.0，SATA 协议，作者 wizardforcel）。

## 2. 共享基础设施

+ `openai.py` — LLM 客户端层：`OpenAIClient`、`ToolsMixin` 工具调用混入及 `base_schema`/`func_schema`/`model_schema` 等 function-calling Schema 构造助手。
+ `util.py` — 通用工具函数：图片/PDF/文本处理（`read_pdf_text`/`read_text`/`write_text`、`epub2html_pandoc`、`is_pic`）、模型序列化与缓存键（`json_dump_model`/`gen_objs_md5`）、提示词渲染（`render_prompt`）、文本相似度（`ngram_jaccard`/`ngram_coverage`）等。

## 3. 小红书体系

+ `xhs_api.py` — 小红书 API 客户端：`XhsClient`（Cookie 加载与请求签名、文件上传、创建图文/视频/纯文本笔记），定义 `XhsApiError` 等异常，提供 `publish_image_note`/`publish_video_note`/`publish_text_note` 等便捷函数。
+ `xhs_img_gen.py` + `xhs_img_models.py` — `xhs-img` 子命令（小红书信息图卡片）：`analyze_content` 内容分析，`_gen_outline_a/b/c` 按三种策略生成大纲，`generate_series` 批量生成 TTI 图片提示词；模型包括 `Style`/`Layout`/`Palette`/`Preset`/`ImagePage`/`Outline`/`ContentAnalysis`/`AudienceProfile`。
+ `xhs_art_gen.py` + `xhs_art_agent.py` + `xhs_art_models.py` + `xhs_art_pmt.py` — `xhs-art` 子命令：文章 → 小红书轮播图 HTML（01fish 色板渲染，`render_cards_html`）与发布文案；模型 `XhsCard`/`XhsCopy`，提示词 `GEN_CARDS_PMT`/`GEN_COPY_PMT`。

## 4. 图文与多媒体内容生成

+ `article_img.py` + `article_img_models.py` + `article_img_pmt.py` — `article-img` 子命令（文章配图）：`ArticleImgAgent` 规划与生成图片，`ArticleImgOrchestrator` 串联流程并输出配图 HTML（支持 Playwright 导出 PNG）；模型 `ImagePlan`/`ImagePage`/`Colors`。
+ `ppt.py` + `ppt_agent.py` + `ppt_models.py` + `ppt_pmt.py` — `ppt` 子命令（网页 PPT）：素材 → 单文件横向翻页网页 PPT（`PptOrchestrator`/`PptAgent`）；模型 `Theme`/`Slide`/`DeckPlan`/`DeckResult`。
+ `jike_art.py` + `jike_art_agent.py` + `jike_art_models.py` + `jike_art_pmt.py` — `jike-art` 子命令：文章 → 即刻发布文案（`JikeArtOrchestrator`/`JikeArtAgent`，模型 `JikeCopy`）。
+ `podcast.py` + `podcast_agent.py` + `podcast_models.py` + `podcast_pmt.py` — `podcast` 子命令：文章 → 播客脚本 + 封面 + 小宇宙文案（`PodcastOrchestrator`/`PodcastAgent`；音频依赖本地 IndexTTS2，未配置时自动跳过音频）。
+ `gzh_art.py` + `gzh_art_agent.py` + `gzh_art_models.py` + `gzh_art_pmt.py` — `gzh-art` 子命令：素材目录 → 公众号出稿 Markdown（01fish 写作风格，`GzhArtOrchestrator`/`GzhArtAgent`，模型 `GzhArticle`）。

## 5. 人脸融合

+ `zhanshimian.py` — `zhanshimian` 子命令：人脸照片 + 多张场景照片 → 融合图（`ZhanshimianOrchestrator`，OpenAI gpt-image-edit，支持逗号分隔列表与 glob 模式）。
+ `zhanshimian_agent.py` — `ZhanshimianAgent`：`fuse_one` 单张人脸融合、`fuse_batch` 批量融合。
+ `zhanshimian_models.py` — 融合数据模型：`FaceFusionInput`/`FaceFusionResult`/`FaceFusionOutput`。

## 6. 信息源与情报

+ `bili_ai_proj.py` + `bili_ai_proj_agent.py` + `bili_ai_proj_models.py` + `bili_ai_proj_pmt.py` — `bili-ai-proj` 子命令：在 B站搜索 AI 相关项目并筛选（`BiliAiProjOrchestrator` 的 `step_search/step_filter/step_output`，`BiliAiProjAgent` 的 `search_videos`/`filter_apps`；模型 `BiliVideo`/`BiliSearchResult`/`AppItem`/`AppList`）。
+ `zhihu_radar.py` + `zhihu_radar_agent.py` + `zhihu_radar_models.py` + `zhihu_radar_pmt.py` — `zhihu-radar` 子命令：抓取知乎推荐流，判断问题与回答是否违背核心观点，并拟定回答大纲（`ZhihuRadarOrchestrator`/`ZhihuRadarAgent`；模型 `ZhihuQAItem`/`Verdict`/`AnswerOutline`/`RadarResult`）。

## 7. 微信与日报

+ `wx_summary.py` — `wx-summary` 子命令：查找微信进程并解密消息数据库，按群组加载消息、LLM 分组摘要，合成跨群综述报告（`find_wechat_process`/`decrypt_db`/`load_group_messages`/`summarize_groups` 等）。
+ `aidaily.py` + `aidaily_agent.py` + `aidaily_models.py` + `aidaily_pmt.py` — `aidaily` 子命令（AI 平权日报）：arXiv/Hacker News 等信源 → 采集、粗筛、去重、LLM 精筛、渲染简报（`AidailyOrchestrator` 的 `step_collect/step_filter/step_dedup/step_enrich/step_render`，`FileLock` 并发锁，支持 `--stage` 单步重跑）；模型 `Article`/`DedupedArticle`/`Enrichment`/`EnrichedArticle`/`RunStatus`。
+ `tests/test_aidaily.py` — aidaily 子命令的 pytest 测试用例。

## 8. 模块约定

每个子命令模块均提供 `reg_subparser(subparsers)` 注册参数并绑定对应的 `xxx(args)` 入口函数，在 `__main__.py` 中被逐一调用注册；LLM 调用统一走 `openai.py` 的 `OpenAIClient`，通用工具统一走 `util.py`。提示词与模型文件随对应子命令并置（`*_pmt.py`、`*_models.py`）。
